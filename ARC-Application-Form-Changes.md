# ARC Application Form — Proposed Changes

Tracking changes to make to the ARC application form (separate from the Guidelines document). These came out of Bill's Google Doc review (Aug 2026).

---

## From Fencing Section

1. **90-day installation deadline:** Add statement to application form: "Installation must be completed within 90 days of approval."
2. **No temporary fence removal:** Application should note that temporary removal of fencing in side/backyards is not permitted except during approved construction.
3. **Fence anchoring:** Application should note that fences shall not be anchored to retaining walls or another fence.

## From Alteration Application Process

2. **Project Completion Letter:** Include a Project Completion Letter with approved applications, to be signed and returned by homeowner upon project completion.
